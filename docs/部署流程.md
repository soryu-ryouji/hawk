# 部署流程

## Hawk App

**Windows**

使用 `tools/install.ps1` 脚本将应用安装到指定目录

```pwsh
.\tools\install.ps1 -Path D:\Tools\hawk\
```

**macOS**

运行 `tools/install.sh` 脚本，应用将自动安装到 Application 文件夹

```bash
./tools/install.sh
```

## Hawk Server

### 安装

```bash
# 输出可运行文件到指定目录
tools/deploy-hawk-server.sh --path /usr/local/bin/hawk-server

# 首次运行需要: 为 hawk 添加用户执行权限
sudo useradd --system --home /var/lib/hawk-server --shell /usr/sbin/nologin hawk

# 将应用安装到 /var/lib 目录
sudo install -d -o hawk -g hawk /var/lib/hawk-server
```

### 启动服务

```bash
sudo -u hawk /usr/local/bin/hawk-server \
     --data-dir /var/lib/hawk-server
```

### 配置 HTTPS 反向代理

以 hawk.example.com 为例：

```nginx
  server {
      listen 443 ssl;
      server_name hawk.example.com;

      # 配置 ssl_certificate 和 ssl_certificate_key

      location / {
          proxy_pass http://127.0.0.1:9100;
          proxy_http_version 1.1;

          proxy_set_header Upgrade $http_upgrade;
          proxy_set_header Connection "upgrade";
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
          proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto $scheme;

          proxy_read_timeout 3600s;
          proxy_send_timeout 3600s;
      }
  }
```

### 使用服务

```bash
# 创建租户，保存输出的 hs_... tenant_key，只显示一次
   sudo -u hawk /usr/local/bin/hawk-server \
     --data-dir /var/lib/hawk-server \
     tenant add --label home
```
